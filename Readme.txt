# Real-Time Object & Human Detection System

An AI-powered real-time object and human detection system built using deep learning and computer vision. The project leverages the YOLOv8 model to accurately detect humans, animals, and vehicles from live camera feeds and video files with high performance and scalability.

---

## 🚀 Features

- Real-time detection of humans, animals, and vehicles  
- Supports both live webcam feed and video file input  
- Bounding-box visualization with class labels and confidence scores  
- Detection logging for analysis and debugging  
- GPU acceleration using CUDA for faster inference  
- Modular and scalable architecture for future extensions  

---

## 🛠️ Tech Stack

- Programming Language: Python  
- Deep Learning Framework: PyTorch  
- Model: YOLOv8  
- Computer Vision Library: OpenCV  
- Hardware Acceleration: CUDA (GPU)
